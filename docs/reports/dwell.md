# Dwell

User Help File: **Stop Dwell Report**

**Introduction:**
The Stop Dwell report displays the average time a bus stays at each stop for different routes.

**Using the Stop Dwell Report:**

- Data is filtering according to the route calendars and timepoints (if present).
- Dwells shorter than 10 seconds, or having just one location record are skipped (to sort out GPS errors).
- The report is organized by route, stop, and date. It displays the stop code, stop name, and dwell time for each stop.
- The stop dwell time is displayed in hours, minutes, and seconds.

You can use the report to understand the average dwell time at each bus stop, which can help an Agency to optimize their routes more efficiently.
