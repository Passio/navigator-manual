# Trip

## Geofence based Trip Report using GPS positions and NOT associated with Routes

**Purpose:**

This report allows you to setup 2 or more geofences in order to define a trip. Once defined, the report counts every time that the vehicle goes into the defined geofences, in order, within a specified period of time. 

> For example, if you setup 3 geofences and define 5 minutes (or 300 seconds) for travel time, and two vehicles enter, then exit those 3 geofences, 2 'trips' will be counted. If they do that over and over again, once per hour, the report will show 6 trips over 3 hours. If however, a vehicle goes from the 1st to the 3 geofence, skipping the 2nd geofence on one of the rounds, it would not be counted and a total of 5 trips would show.
