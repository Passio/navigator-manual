# Assignment

This report, titled **Vehicle Assignment** displays information about vehicle assignments for a specific date and time range.

Each row of the report represents a different assignment and provides the following information:

- Assignment time: the time that the assignment was made
- Route: the name of the assigned route
- Job: the specific job or duty associated with the assignment
- Segment block: the block or section of the route associated with the assignment
- Scheduled start time: the time that the assignment is scheduled to begin
- Adherence: a blank field indicating whether the assignment is on schedule
- Vehicle: the identification number of the assigned vehicle
- User: the department or organization responsible for the vehicle and assignment

To use this report, select the desired date and time range for which you want to view vehicle assignments. The report will display all assignments made within that range, organized by assignment time.

The report can be used by managers or coordinators responsible for managing vehicle assignments, route planning, and scheduling. It provides a quick overview of all assignments made within a certain time frame, allowing for efficient management and organization of vehicle resources.
