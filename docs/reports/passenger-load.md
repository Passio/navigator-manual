# Passenger Load

**Passenger load report** 

Technical Help File: How to read and interpret the Passenger Load Report

**Overview**
The Passenger Load report provides information on the number of passengers who have boarded or alighted at different stops for different routes for a given time period. This document provides guidelines on how to read and interpret the report.

**Report Structure**
The report contains the following columns:

1. Date – The date the Trip ran.
2. Time – The time the passenger load was updated at the Segment stop.
3. Time point – The scheduled time for the Segment stop.
4. Route – The Route Name and Route Short Name.
5. Segment block – The Trip Group the Trip is on.
6. Trip – The Trip name as listed in the Block/Job.
7. Trip# – The Trip sequence as listed in the Block/Job.
8. Vehicle – The Vehicle Name.
9. Driver – The Driver Name.
10. Segment stop – The name of the Segment Stop where the passenger load was updated.
11. Pax load – The number of passengers on the Vehicle at the Segment Stop.
12. Percentage – The Pax load as a percentage out of the Vehicle Total Capacity.

**Reading the Report**
The report lists the trips for different routes and the passenger load at different stops for a given time period. To read and interpret the data:

1. Identify the route and the trip sequence number to identify the trips.
2. Look for the segment block and the stop name to determine the stops where the passenger boarded or alighted.
3. Check the Pax Load column to identify the number of passengers who boarded or alighted.
4. Check the Percentage column to determine the percentage of passenger load in relation to the total capacity of the vehicle.

**Filtering the Report**
To filter the report and find specific information, utilize the search and filter options of your spreadsheet program. For example:

1. To filter by date or time, use the filter function on the Date and Time columns.
2. To filter by route or trip sequence, use the filter function on the Route and Trip columns.
3. To filter by stop name, use the filter function on the Segment Stop column.
4. To filter by percentage of passenger load, use the filter function on the Percentage column.

**Conclusion**
The Passenger Load report provides valuable information on passenger load at different stops for different routes for a given time period. Understanding how to read and interpret the data is useful for analyzing passenger load trends and service performance. The search and filter function of your spreadsheet program can be used to isolate specific information for your analysis.
