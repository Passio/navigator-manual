# Transit

Help File: **Route Transit Time Report**

The Route Transit Time report is a tool that provides valuable information about the transit times of various routes. This report shows average transit time data for the past seven days, as a default, by route. The data in this report comes from primary device location records within stop geofences. This report calculates the average time since the last stop by the same bus on a stop by stop basic. 

**Understanding the Report:**

- The report displays the transit times for each route and day under the respective column headings.
- The timings are displayed in hours, minutes and seconds format.

The "-" symbol indicates missing data for that particular day or route.

**How to Use the Report:**

- The report can be used to identify the expected transit time for a particular route on a specific day.
- The data can be used to plan travel time for individuals who use public transport.
- The report can help to identify any changes in the transit time for the same route on different days.

**Note:**
- The report only displays transit information for the routes mentioned in the report.
- The transit time displayed in the report is an approximation and may vary depending on several factors like traffic and weather conditions.


*Data is filtered according to the route calendars and timepoints (if present). Rounds longer than 3 hours are skipped (to discard overnight data).
