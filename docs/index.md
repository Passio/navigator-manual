# Passio Navigator Manual

This is the user manual for **Passio Navigator**. It is the same help content
shown by the **?** buttons inside the application, published here so it can be
browsed, searched, and linked to.

Press **Ask** in the header to search in plain language — describe the task
rather than guessing the name of a screen. "How do I track deadhead miles?"
works better than "yard".

## A note on permissions

What you can see and do in Passio Navigator depends on the solutions your agency
has purchased and the permission level assigned to your user account. Pages in
this manual describe the full feature set, so you may not see every screen or
button described here.
