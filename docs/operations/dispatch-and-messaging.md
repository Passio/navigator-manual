# Dispatch & Messaging

## Help file for Dispatch and Messaging

### Broadcast Message

Clicking 'Broadcast' allows a dispatcher to communicate with MDTs in the field.

**Types of communication**
1. Free text
2. Voice Announcements played over vehicle speakers
3. LED message displayed in vehicle
4. Disable Emergency Mode

**MDT Recipients**
1. All vehicles (default)
2. Selected vehicle (choose with vehicle dropdown list)
3. All vehicles on a specific route (choose with segment dropdown list)


Vehicle assignments can not be updated when the vehicle status is displayed as unavailable
