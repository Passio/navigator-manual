# Forms

Form builder help file


Use **+ New Form** in order to create a new Inspection form available to Passio One users. 

The following form fields are supported. 

- Text input - free form text input box
- Header - Larger header text with no input field
- Description - Smaller section text with no input field
- Checkbox - checkbox Yes No
- Pass/fail - 4 toggle states; Pass, Fail, N/A, or blank
- Dropdown - Selection list
- Radio button - Single selection list
- Text check - checkbox with text input 
- Date - date selection field
- Time - Amount of time selection field
- Datetime - Clock time selection field
- Number - number input field
- Picture - take or select a picture
- Signature - finger draw field
- Vehicle Select - dropdown selection from Vehicle name list
- Vehicle Graphic - dropdown selection from Vehicle type list
- Rating - 5 star rating
