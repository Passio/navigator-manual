# Dashboards

## Business Intelligence Dashboards are used to group together relevant reports

Some features include:
- Multiple dashboards can be created by anyone with Write permissions
- All dashboards are shared with all team members that have access to the Business Intelligence reports
- Within each dashboard, customized reports can be created using various data sets, filters, grouping, and presentation
- Dashboards with the on-page reports can be emailed as a PDF
- Individual BI reports can be emailed separately

To find out more on how to create the BI reports, type in "dashboard" into the KB link in Navigator.

## Creating Dashboard Reports

1. Click '+ New report'  
2. Name report  
3. 'Save report'  
4. Refresh browser page to see new report  
5. Click on the 3 dots in the upper right-hand corner of the report  
6. Click 'Edit'  
7. Click 'Timeframe'  
8. Enter fixed or relative date  
9. 'Save'  
10. 'Save report'  
11. Click 3 dots in the upper right-hand corner of the report  
12. Click 'Refresh'  
13. Refresh your browser to see results  
14. Click 3 dots in the upper right-hand corner of the report  
15. Fill out the rest of your report criteria (chart type, data source, filters, groupings, size etc.)

**Refresh report after changes are made. Refresh the report itself to see data changes and refresh the browser to see formatting changes.**

## Settings

**SEMESTER NAME**  
- You can change the name of the filter from Semester to something else (i.e. Quarter, Semi Annual, etc.)

**SEMESTERS**  
- Add all semesters to this list for reporting purposes

**SEMESTER RULES**  
- Create any name needed to segment reporting into semesters, quarters, or other grouping desired  
- Year start means the year starts on the date of that range (fiscal year vs calendar year)

## Limitations

- Heatmaps reports will not properly export to PDF
