# Drivers

> _The ability for you to read or write different pages and action buttons is based on the solutions purchased and the user level permission assigned._

## Driver Configuration and Usage Guide

Welcome to the Driver Configuration and Usage Guide for Passio! This guide will provide you with all the information you need to effectively manage and utilize drivers within the Passio system.

### Definition

In Passio, drivers (also known as operators) are the individuals responsible for operating the vehicles. They are the primary users who interact with the on-board Mobile Data Terminal (MDT), if available.

### Driver Configuration Page

The Driver Configuration page is where you can input and edit driver information, which will be displayed on various Passio modules such as the MDT, Live Map, Dispatch & Messaging, and more.

To add a new driver, simply click on the "**+ Add driver**" button if you have write access. It's important to establish a naming convention for identifying your drivers. You can use different approaches, such as using the first initial and last name (e.g., J. Smith), last name and first initial (e.g., Smith, J.), an abbreviation (e.g., SMIT for Smith), or an identifier (e.g., Driver34). The driver name you enter will be displayed on various system displays and reports.

### Viewing and Editing Driver Details

To view or edit the details of a driver, click on their name in the Driver Configuration page. Most of the fields on this page are self-explanatory. You can find helpful tooltips by hovering over the field text to understand the purpose of each field. However, some fields may require further clarification:

- **Driver Image**: Currently used for internal reference only to help identify your Drivers

- **Hide on device**: This option allows you to hide the driver's name on the MDT driver app. It is useful when a driver is not currently available.

- **First name, Last name, Email, & Phone**: These are not required but allow agencies to have detailed driver information.

- **Public name**: This is the name that will be displayed on Passio GO if you are using this particular solution and have it enabled.

- **PIN**: If a PIN is defined, the driver will be required to enter a PIN code after selecting their name.

- **Licenses**: Here, you can specify the licenses that the drivers are certified for, as defined in the Settings. For example, CDL (Commercial Driver's License) or air-brakes.

- **Allow multiple blocks**: There are three options:
  -   'Cannot overlap' means that a single driver can only be assigned to a single, non-overlapping, piece of work (Job).
  -   'Can overlap with warning' means that a single driver can be assigned, but a warning will be displayed to the dispatcher informing them of this conflict
  -   'Can overlap without warning' is useful to use with generic driver names that an agency may use for drivers to select or dispatchers to assign when their name and profile may not yet be in the system or if the agency isn't using driver-specific names.
  
- **Luminator code**: If you have a driver LED sign, this field represents the code assigned to the driver in Luminator's database.

### Training Mode

Selecting a Training ONLY driver puts Passio into training mode, allowing operators to run revenue routes without impacting ridership, NTD, or any other reporting data.

To enable training mode:
	1.	Create a new driver profile.
	2.	Enable the **Training ONLY** option.

Once an operator logs in with a **Training ONLY** driver, they can select any route and navigate through stops as usual. They can also mark pretend riders on and off the vehicle to simulate pickups and drop-offs. None of this activity will affect reporting or analytics.
