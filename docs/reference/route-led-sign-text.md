# Route LED Sign Text

Segment LED Sign-Text help

Best Practices Moving forward: 9.15.23 


 
Transit Buses	 

 Front Sign:  

  * Use [FONT6] for single line text 

  * Use [FONT3] double line 

Side Sign: Use [FONT4] single line scrolling if longer than width 

 Shuttle Cut-aways: 

Front sign: 

  * Use [FONT6] - only single line text 

Side Sign:  

  * Use [FONT3] - scrolling if text is wider than sign 

 

Best practices moving forward: 6.7.23 
- Capital first letter, lower case 
- Side sign will scroll if it does not fit in one view 

 
Rotating Side Sign: (Example) 
[FONT4][DELAY3][BRA]Federal Cir[BRA][FONT4][DELAY3] to Terminals[BRA][FONT4][DELAY3]1, 4, 5, 7, 8[BR] 
 
Scrolling Side Sign: (Example) 
[FONT4]Federal Cir to Terminals 1, 4, 5, 7, 8 (Scrolling checked) - 9 seconds 

 

Possible [FONT] sizes 

 Front Head signs (except Cutaway) – 16 high, 160 wide. Use 8 font single line or 3 font double line 
Side signs: 

  * Orion: (12112) 12 high, 112 wide. Use font 4, 5 or 6 Font single line 

  * Proterra: (1696) 16 high, 96 wide. Use 8 font single line or 3 font double line 

  * New Flyer: (16128) 16 high, 128, wide. Use 8 font single line or 3 font double line 

 Cutaways 

  * Front Sign: (12112) 12 high, 112 wide. Use font 4, 5 or 6 Font single line 

  * Side Sign: (864) 8 high, 64 wide. Use 3 font single line
