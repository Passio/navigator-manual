# Yards

Help file for Fleet Logistics -> vehicles
<p><B>Vehicle Status Icon</B>
<LI>RED CIRCLE - One or more devices are offline. Refer to 'Devices' column for further insight. During vehicle start up or shut down, devices boot up and shut down at varying times depending on the devices configuration. <b>If devices are red for less than 5 minutes, it is typically not a cause for concern.</b> See green 'KB' (Knowledge Base) button for troubleshooting steps if devices are offline for longer. 
  <LI>GREEN CIRCLE - All devices are reporting online. No action to take.</li>
  <LI>GREEN OUTLINE WITH WHITE CENTER - Devices online, vehicle out of service.</LI> 
  <BR><b>If vehicle is mistakenly In Service while powered off, devices will show as red. This is not a cause for concern. The Service Status should be adjusted to Out of Service.</B>
    
 <BR><B>Devices</B>
    <li>Green-reporting and active, giving a heartbeat.
      <li>Grey-not on, not in service.
        <li>Red-in service, not reporting.
        
  <BR><b>Tracking</b>
          <LI>Online/offline status of GPS tracking device</LI>
  <BR><b>Accuracy</b>
<LI> The accuracy field can be defined as 'System Accuracy'. 
<LI> It is measuring the performance of the system configuration and setup. 
<LI>It is comparing the 'On' and 'Off' counts for the last 48 hours. It includes all of the Passenger types in the Ridership Report. 
<LI>If the rating is 100%, it means that there were the same amount of boarding counts as alighting counts for that 48 hour period.
  
  <BR><b>Wrench Icon</b>
  <LI>Use to adjust vehicle Status. Ex. Available, Not Available.</LI>
      <BR><b>Globe Icon</b>
  <LI>See vehicle location on Live Map.</LI>
